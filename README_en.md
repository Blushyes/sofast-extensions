# Sofast Extensions

[中文](README.md) | English

This repo contains example extensions for [Sofast](https://sofast.fun).

If you’re interested in any plugin, feel free to modify it and send a PR — contributions are welcome!

Examples
- `extensions/todolist`: a minimal todo list plugin.
- `extensions/snake`: a simple Snake game example.

Docs & Feedback
- Plugin docs: https://developer.sofast.fun
- Questions or need an API while developing? Please open an issue, or join the Rukuai (如快) feedback QQ group: 683415578.
